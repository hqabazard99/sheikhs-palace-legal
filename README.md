# Sheikh's Palace — legal pages

Public pages for the Sheikh's Palace app, served by GitHub Pages at
https://hqabazard99.github.io/sheikhs-palace-legal/

- `privacy/` — Privacy Policy (English + Arabic). Linked from the App Store listing and the AdMob consent message.
- `support/` — Support page and FAQ (English + Arabic).
- `index.html`, `404.html` — built from the privacy page by `node build.mjs`.

Edit `privacy/index.html` (or the texts in `build.mjs`), run `node build.mjs`, then commit and push:
GitHub Pages republishes in about a minute. app-ads.txt for this site lives at the domain root,
https://hqabazard99.github.io/app-ads.txt (repo hqabazard99.github.io).
